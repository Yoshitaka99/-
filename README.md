# X Impressions Playbook Skill

X（旧Twitter）のポスト自動生成エンジン。ジャンルを指定すると、ろじん式・駒居式の型でポストを量産する Claude Code Skill。

ろじん（@fiction_log、Levela CXO・X顧問累計900社）と駒居康樹（@koki_komai、Levela代表）の**実ポスト40本を回収・構造分解**し、査読研究（バイラルの科学）とXアルゴリズム公開情報（2023年オープンソースコード＋2026年Grok移行）で「なぜ伸びるのか」を裏付けた上で、AIが実行可能な生成仕様に落としています。

## 使い方

このリポジトリを Claude Code で開くと、Skill が自動で認識されます。

- **ジャンル起動（メイン）**: 「筋トレジャンルでポスト作って」→ コンセプト設計 → ネタ収集コマンド → 型付きポスト3案 → 週間カレンダー
- **添削**: 「このポストを添削して」→ 誤診の修正（時間帯・プロフィールのせいにしない）→ 型の当て直し
- **戦略相談**: 「伸びない理由を診断して」→ 因果メカニズムから回答

## 核心の言語化（なぜこの人たちは伸びるのか）

1. **元ネタの市場規模がインプの上限を決める** — 持論ではなく、注目が既に集まっている元情報に解説を乗せる（ろじん）
2. **いいねではなく会話を買う** — リプ往復はいいねの150倍のシグナル。リプ収集装置を仕込む（実測: いいね329に対しリプ1,599）
3. **加点より減点回避** — 通報1件＝いいね約700件を打ち消す
4. **初速30〜60分が全て** — 投稿後60分のリプ全返信までが「投稿」
5. **爆発は「炎上」か「保存型Article」** — 駒居の実測2,397万viewsは負のバイラル。健全に再現すべきはブックマーク型長文（ブクマ2,594の実例）
