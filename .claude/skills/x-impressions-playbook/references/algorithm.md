# Xアルゴリズム攻略リファレンス（2025〜2026年版）

凡例: 【事実】= 公式発表・オープンソースコード由来 / 【経験則】= 実践者・分析会社の知見 / 【推定】= 二次情報からの推測

## 1. エンゲージメント重み（2023年公開コード）【事実】

[twitter/the-algorithm](https://github.com/twitter/the-algorithm) の Heavy Ranker 係数（いいね=0.5基準）:

| アクション | 重み | いいね比 |
|---|---|---|
| リプライに投稿者が返信（会話往復） | +75.0 | 150倍 |
| リプライ | +13.5 | 27倍 |
| ブックマーク | +10前後 | 20倍 |
| 滞在2分以上/動画50%視聴/プロフクリック | +10〜11 | 約20倍 |
| リポスト | +1.0 | 2倍 |
| いいね | +0.5 | 基準 |
| ミュート/ブロック | **-74.0** | — |
| 通報 | **-369.0** | — |

**結論: 通報1件はいいね約700件分を打ち消す。加点を狙うより減点を踏まないことが数値的に重要。**
※2026年新体制では正確な重みは非公開。上記は「方向性の参考値」として使う。

## 2. パイプライン構造【事実】

- For Youは毎セッション約1,500件の候補（In-Network約50% / Out-of-Network約50%）→ Heavy Ranker（現Phoenix）がスコアリング → フィルタ。
- **Author Diversity Penalty**: 同一投稿者の投稿は連続表示されないようスコア自動減衰。連投・セルフリポストによる露出稼ぎは構造的に無効。
- **TweepCred**（著者評価スコア0-100）: フォロワーの質・FF比・アカウント年齢・エンゲージ履歴で決定。65未満だと配信候補に入る投稿数が制限されるという解析あり【推定】。
- 時間減衰: 投稿は約6時間ごとに可視性が半減。

## 3. 2026年新アルゴリズム（Grok/Phoenix）【事実】

- 2026年1月オープンソース化。xAIのGrokと同じTransformerアーキテクチャ（Phoenix: two-tower、19種のエンゲージメント確率を予測）。
- Grokが全投稿・全動画を「読んで」関心マッチング。最適化目標は「unregretted user-seconds（後悔しない利用時間）」。
- **センチメント評価**: 攻撃的トーンはエンゲージが高くても配信縮小。ポジティブ・建設的トーンは配信拡大【推定】。
- **ネガティブ7カテゴリ**（暴力・成人向け・スパム・違法・ヘイト・暴力発言・自傷）の自動判定。攻めた表現で踏むとアカウント全体の評価低下。
- フォロワー規模6階層別の評価軸 → 小規模アカウントは大規模と同じ土俵で戦わされない。ニッチで会話を生めば小アカでも拡散が起きる。

## 4. 収益化ルールの変遷【事実】

| 時期 | 変更 |
|---|---|
| 2024/10 | 収益分配が「Premiumユーザーからのエンゲージメントベース」に |
| 2025/10 | 外部リンクペナルティの緩和を公式発表（ただし実測ではリンク投稿は依然不利） |
| 2026/1 | **リプライ欄の広告が収益対象外に（リプライ収益ゼロ化）**。収益基準は「PremiumユーザーのホームTL閲覧」へ。収益プールは2倍以上に拡大 |
| 2026/2 | X API v2でLLM自動リプライを制限（インプレゾンビの技術的遮断） |

→ 「リプ欄でインプを稼ぐ」戦略は収益面で死んだ。本体ポストがPremiumユーザーのFor You/ホームTLに載ることが全て。

## 5. 投稿フォーマット【経験則＋一部事実】

- 強度: 長文/記事（Premium・滞在時間を直接稼ぐ）≒ 60秒級ネイティブ動画 > 複数画像（2-4枚）> テキストのみ。
- 動画: ネイティブアップロード必須。60秒未満が最も配信ブースト、視聴完了率50%以上で追加リーチ。縦型は約2.5倍のエンゲージメント。
- 構造化ライティング「結論→理由→具体例」はGrokのテキスト解析と読者の両方に効く。
- ブックマーク誘発設計: チェックリスト・比較表・手順形式。
- ハッシュタグ依存は低下（セマンティック埋め込みが主）。タグ乱用はスパムシグナル。
- スレッド: 滞在時間を稼げる一方、2026年は「単独投稿の完結性」評価が厳格化したとの見解もあり、見解が割れている【要検証】。

## 6. 運用戦術【経験則】

- **初速30〜60分のエンゲージメント速度が最重要**。2026年の重複表示抑制により初回露出での反応獲得が以前より決定的に。
- 投稿直後1時間はリプに全返信（+75の会話往復シグナルを自分で量産する行為）。
- 投稿時間: Buffer（870万ポスト分析）は火曜9時>水曜10時、平日9-11時が安定。日本語圏の実践値は朝6時と夜21時。自分のオーディエンスのアクティブ時間が最優先。
- 頻度: 毎日1本の完結型高品質投稿 > 1日5本の薄い投稿。1日2-3投稿超は逓減。
- 外部リンク: Buffer実測（1,880万ポスト）で非Premiumのリンク付き投稿はエンゲージ率ほぼ0%。**リンクは本文に貼らず、伸びてからリプ欄へ**。
- Premium: 実測で約10倍のリーチ。収益化を目指すなら実質必須。
- 小規模アカウント（〜2,000フォロワー）は労力の8割を「他人のスレッドでの実のあるリプライ」に（プロフクリックの入口）。
- FF比1.0〜1.5、1日のフォローは60人以内が安全圏【経験則】。

## 7. やってはいけないこと

1. 通報・ブロック・ミュートを誘発する投稿（炎上商法は数値上も割に合わない）
2. エンゲージメントベイト（「いいねした人に配布」「RTで拡散」型）— Grok分類器が検出・降格。Muskは「エンゲージメントファーミングは凍結」と明言
3. 本文へのURL直貼り
4. コピー投稿・重複コンテンツ（重複検出でフィルタ）
5. 自動化くさい挙動（機械的に規則正しい投稿時刻、AI量産テンプレ文）
6. フォロワー購入・相互水増し（エンゲージ/インプ比が壊れ評価スコア低下）
7. グレーゾーンコンテンツ（ネガティブ7カテゴリ）
8. コミュニティノートが付く投稿（配信ペナルティ）

シャドウバン要因: 短時間の大量フォロー/解除、アフィリンク連投、類似投稿の反復、ハッシュタグ乱用、複数アカウントでの同型投稿。対処は原因行動を止めて数日休ませるのが最短。

## 8. 優先順位まとめ

1. 会話を設計する（リプ往復が最強シグナル。問いかけ＋1時間以内全返信）
2. 滞在時間を稼ぐ形式（長文/記事、60秒級動画、保存される表・リスト）
3. 初速30-60分に全てを賭ける
4. ニッチ1〜2テーマに固定し、プロフィール・固定ポスト・投稿を一気通貫
5. 量より密度
6. リンクは本文に貼らない、Premiumには入る
7. 減点を絶対に踏まない
