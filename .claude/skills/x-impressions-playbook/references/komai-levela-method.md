# 駒居康樹 / Levela式 SNSインフルエンス構築メソッド

駒居康樹（X/Instagram: @koki_komai、1996年生）。株式会社Levela代表取締役。Instagram特化スクール「SnsClub」運営、設立3期目で年商15億円達成見込み（同社発表）。総フォロワー15万人超。「SNS版令和の虎」元主宰。

注意: 同社の実績数値（受講生数・平均投稿数など）は自己申告で第三者検証はない。また2026年3月に偽装請負疑惑で炎上した係争的文脈があるため、引用時は「同社発表」と明記する。

## 1. 駒居式・個人ブランディングの型

### 型A: 逆境経歴ストーリーテリング
「【あんまり言ってこなかった経歴】」で始め、時系列を「↓」で区切る箇条書きで語る:
> 6歳〜10歳 児童養護施設 → バスケ → 貧乏で新聞配達5年 → 神戸大 → ソフトバンク営業全国No.1 → インスタ4ヶ月で5万フォロワー → 起業 → 年商15億

ポイント: **同一の自分史ナラティブをX・note・インタビューで何度も再利用する**。一貫した物語が個人ブランドになる。逆境の底が深いほど現在の実績が引き立つ。

### 型B: 金銭・規模インパクト
- 具体的な金額・人数を投稿の主役にする（「スタッフ50人・総額1,500万円のシンガポール旅行」「1期目は韓国、2期目はシドニー、3期目はシンガポール」）。
- **プロフィール表示名自体に金銭フックを埋める**: 「駒居 康樹【フォロワーに100万円を配る社長】」。
- 企画は「金銭フック＋大義名分＋ストーリー」の三点セットにする: 100万円配布 × 児童養護施設への寄付宣言 × 自身が施設出身という経歴の接続。
- 生徒実績の定量報告（「直近で27個の万垢を輩出」等）を継続投稿して社会的証明を積む。

### 型C: 批判への「あえて言及」
ネガティブな声を自分から取り上げて反論・物語化する（「【弊社は怪しいことをしてるらしい】…とスタッフから。」）。大量のインプレッションを獲得できるが、批判も拡大するリスクを伴う両刃の剣。

### 型D: note連載型ストーリーテリング
起承転結構成 × 具体的数字（月100万円、全国2位）× 関西弁ツッコミで親近感 × 末尾にCTA＋次回予告（継続接触の設計）。

### 型E: メディアの複線化
個人アカウント＋番組型メディア（SNS版令和の虎）＋自社YouTube＋TikTokの複線運用。個人の顔と「箱」を両方持つ。

## 2. SnsClub「再現性カリキュラム」の構造

売り文句: 「ロードマップ通りに進めた生徒は平均67投稿（後に49投稿に更新）でフォロワー1万人」。**再現性の数値化そのものが最強のマーケティング**という思想。

公開情報から復元できる構造（添削駆動型）:
1. 需要のあるジャンル×独自の切り口のコンセプト設計
2. 型（キラーワード集・テンプレ）で投稿の質を初期から担保
3. 投稿ごとに添削・インサイト分析で改善
4. バズ（リールの外部リーチ）でフォロワー転換

提供教材: バズるキラーワード1,000選／Canvaテンプレ100枚／チェックシート100項目／ジャンル別トレンドリスト（TikTok1,000本・YouTube1,500本キュレーション）／全クリエイティブ添削（講師は現役インフルエンサーのみ採用）。

## 3. Levela公式ブログの具体的テクニック

### ジャンル・コンセプト設計（Xにも転用可能な核心）
- **「競合ゼロ＝お宝」は誤り。需要のあるレッドオーシャン×独自の切り口が正解。**
- 選定5ステップ: ①人気ジャンルから出発 ②自分の属性・専門性の棚卸し ③掛け合わせ（料理×育児等）④競合リサーチ（競合20〜100アカウント、上位が1万フォロワー以下なら勝ち筋）⑤収益から逆算
- ペルソナは性別・年代・居住形態まで絞る。プロフィールに「誰に・何を・どのように」を明記。「初心者成長日記」として物語化。同一ジャンルで最低30〜60投稿は継続。

### バズの作り方（Instagram文脈だが原理は共通）
- 冒頭3秒フック: 完成映像先出し／大文字テキスト「99%の人が知らない〜」／ネガティブ訴求「まだ◯◯してるの？」
- **シェアされる設計が最重要**（DMシェア率）: チェックリスト・比較表・あるあるネタ・意外性
- 投稿時間: ピーク（朝7-9時・昼12-13時・夜19-22時）の**15〜30分前**に投稿
- 分析: 保存率2%以上を基準にコンテンツを判定し、当たり構成を横展開。バズ投稿のアレンジ再投稿で再成長。
- 禁止: エンゲージメントベイト、無関係タグ、フォロワー購入・相互フォロー（維持率を毀損）

### 目標設定メソッド
夢を「来年春・家族4人・ハワイ5泊7日・予算80万円」レベルまで具体化 → 費用を正確に計算 → 期限を切る。「成功者と失敗者の差はやったかやらなかっただけ」。

## 4. 組織的な発信力量産体制

- 提携インフルエンサー200名超・スタッフ600人超のギルド型組織。講師＝現役インフルエンサーのみ採用し、マニュアル化とトレーニングで品質を標準化。
- **影響力のM&A**: ろじん氏のX顧問事業を3.04億円で買収（X事業の教育体制欠如を金で解決）、YouTube「あおの暮らし」（登録2.8万人）を運営会社ごと買収。「個人の発信力・信頼×組織の教育ノウハウ」の融合モデル。
- 成功した生徒の口コミが広告不要の集客チャネルになる構造（「そこまでやるかをデフォルトに」のサポート → 口コミ）。
