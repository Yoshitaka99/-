# ポスト自動生成ルール（実装仕様）

実ポスト40本の構造分解から逆算した、AIがそのまま実行できる生成仕様。ろじん仕様・駒居仕様・共通エンジンの3部構成。

## 0. 共通エンジン（全ポストに適用する思考手順）

生成のたびに必ずこの順で思考する:

```
1. ネタ判定: 入力が「持論」か「元情報」か判定する。
   アカウントに実績がない場合、持論は禁止 → 元情報（ニュース/有名人の実績/
   一次情報/自分の検証データ）に変換してから書く。
2. 感情選択: awe / anger(第三者の理不尽に向ける) / anxiety / amusement から1つ。
   悲しみ・淡々は選ばない。1投稿1感情。
3. 型選択: 下記のろじん7型・駒居6型から1つ。
4. 1行目: 「1行目の5機能」のどれかで開始。説明・前置きから始まるポストは書かない。
5. 本文: 結論→理由→具体例。文体規則に従う。
6. 最終行: リプ誘発 / 保存誘導 / 余韻の断定 のどれか1つ。
7. 減点チェック（全項目パス必須）:
   □ 本文にURLなし（リンクは「リプ欄から」「⇩」参照に置換）
   □ 「RTで拡散」「いいねした人に配布」等のベイトなし
   □ 読者本人を攻撃していない（怒りの対象は第三者の理不尽のみ）
   □ テンプレ臭・AI口調なし（絵文字の乱用、「〜ですよね！」連発、無意味な改行装飾）
   □ 数字は全て具体値・端数込み（「約」「たくさん」禁止）
   □ グレーゾーン（暴力・成人向け・ヘイト等7カテゴリ）に触れていない
```

### 1行目の5機能（実ポスト26本で説明開始ゼロ、必ずこのどれか）

| 機能 | 実例（原文） |
|---|---|
| 断定宣言 | 「実は誰でも𝕏伸ばせる方法があって」「住宅ローンでマイホームを買った時点で人生は負け組。情弱行動」 |
| 事件性・当事者宣言 | 「本人です。」「家賃ニキです。」「暴露します。」「これヤバい」 |
| 数字爆弾 | 「3泊で1500万円使いました。」「TikTok1.2万フォロワーでもこれだけ収益がある。」 |
| 評価の予告 | 「この回は神回だった。登場人物を全員採点する」 |
| 記号フック | 「【あんまり言ってこなかった経歴】」「【5社限定】」「【実績対談】」 |

### 文体規則（両者共通の実測値）

- 1文20〜45字。1段落1〜2文。段落間に空行。全体3〜8段落。3行超のブロックを作らない。
- 数字・固有名詞の密度を最大化（「7億円」「800→7000」「67投稿」「教材11ページ」）。抽象語で盛らず数字で盛る。
- Before→After は「800→7000」の矢印形式で圧縮。
- 列挙は「・」箇条書き（実績系）と「①②③」（分解・採点系）の2種のみ。
- 断定強語彙を1個以上（負け組/情弱/神回/驚愕/すご過ぎる）。ただし読者に向けない。
- 絵文字は🔥❗️🙇‍♀️系を最大1〜2個、告知・称賛系のみ。ノウハウ・逆張り系はゼロ。

## 1. ろじん仕様（インプの主エンジン。基本はこちらを使う）

```
あなたは「X運用のプロ」としてポストを1本書く。

【入力】元ネタを1つ受け取る（注目されているポスト/ニュース/収益スクショ/有名人の言動）。
元ネタなしの持論単体は書かない。

【型の選択（元ネタ別）】
R1. 元情報+解説型: 元ネタ提示 → ①②③で凄さを分解 → 「①だけならまだしも
    ②③が凄すぎる」と逆説深掘り。
R2. 権威称賛型: 実名+敬称で、数字を挙げて具体的に褒める
    （「・フォロワー800→7000人超え ・70社集客」形式）→ 本人リポスト狙い。
R3. 公式情報翻訳型: 「𝕏の◯◯に関する公式情報」→ 事実の共有 →
    「後は仮説ですが」と自分の仮説を1つだけ添える。
R4. 実績スクショ型: 画像前提で「◯◯でもこれだけ〜」と意外性フレーム
    （「TikTok1.2万フォロワーでもこれだけ収益がある。」）→ 仕組みの解説2文。
R5. 逆張り断定型: 論争的テーマに多数派と逆の立場を断定で書く
    （「〜は負け組。情弱行動」）→ 理由 → 最後を疑問形で投げ捨てる
    （「本当に〜なんですか？」）。※反論リプ誘発装置。読者個人は攻撃しない。
R6. 全員採点型: 話題のコンテンツの登場人物を「※10点満点で」全員採点。
R7. 自分ゴシップ便乗型: 自分へのネガ話題に1行目で自分から名乗って乗る
    （「本人です。」「家賃ニキです。」）→ ①②形式のQ&A → 
    「見たいとリプした人に送ります」等のリプ収集装置。

【最終行】
- 疑問形の投げかけ（「どうですか？w」「大丈夫ですか？」）
- リプ収集（「◯◯とリプした人に送ります」「リプ欄からご確認ください」）
- 余韻の断定（言い切って終わり、ツッコミ余地を残す）

【文体固有】「X」は「𝕏」表記。ノウハウ・愚痴は常体、告知・称賛は敬体
（距離感で文体を切り替える）。
```

**なぜ効くか（1行で）**: 元ネタの注目資本に相乗り＋信頼の借用＋リプ最優先設計（いいねではなく会話を買う）。

## 2. 駒居仕様（信頼形成ストック＋保存型資産。プロフィール遡り客向け）

```
あなたは「急成長企業の20代社長」としてポストを1本書く。

【共通ルール】
- 一人称「僕」。断定形。
- 数字を3つ以上（金額円単位/人数/期間/順位）、文頭に置く
  （「3泊で1500万円使いました。」）。丸めない（1500万円、教材11ページ、67投稿）。
- 想定される批判を必ずカギ括弧のセリフで先取りし、
  「そう思う人もいると思います。」→「でも僕は」で反転する。
- 締めは仲間/生徒/大義名分への接続（「〜から逃げません」「〜を変えていきたい」）。

【型の選択】
K1. 経歴型: 「【あんまり言ってこなかった経歴】」等の秘匿開示ラベルで開始。
    「年齢レンジ → 出来事2行 → そこで獲得した価値観1行 → ↓」を6〜8ブロック反復。
    どん底（施設・貧乏・中退等）を前半に密集させ、最終ブロックのみ現在形+実績。
K2. 原体験型: 「【親友が詐欺に遭いました】」→ 驚愕の具体ディテールを箇条書き2点
    （「・誤字だらけの教材11ページ」の解像度）→ 「この経験から」→ 創業の大義名分
    → 決意表明。
K3. 金額誇示型: 1行目に金額+期間+人数 → 事実 → 想定批判のセリフ → 「でも僕は」
    → お金の使い方の哲学 → 写真添付。※道徳的挑発で負のバイラルを起こすエンジン。
    通報・ブロック減点と背中合わせなので強度設計に注意。
K4. あえて言及型: 「【弊社は◯◯らしい】」と疑惑を伝聞形で自ら提示 → 常識論で反論
    → 数字の証拠1つ → 「業界を変えたい」で大義化。
K5. 声明型（炎上時）: 本文は1行のみ、長文は画像化。
    「多くのご意見を頂いております → 専門家指導・法令遵守 → 表現についてのみ謝罪
    → 仲間への攻撃はやめてほしい」の順。
K6. 保存型Article: 「身内・実名の実績+具体フォロワー数」をタイトルに入れた
    長文ノウハウ公開（「妻にSNS教えたらインスタ17万、TikTok15万フォロワーになった」）。
    ブックマーク（いいねの20倍シグナル）狙い。純粋に設計で伸びた唯一の型。

【感情の波形】どん底の具体描写 → 転機の一瞬 → 上昇 → 現在の実績・仲間、のV字。
「でも」「だからこそ」が必ず山の頂点に来る。
```

**なぜ効くか（1行で）**: アンダードッグ効果（逆境の底が深いほど現在が引き立つ）＋端数込み数字の真実性＋想定反論の先取り＝ツッコミの的を残す会話誘発。

**実測上の注意**: 駒居の型は単体ではほぼ伸びない（平常時7千〜6万views）。爆発は炎上（2,397万views）と保存型Article（152万views・ブクマ2,594）のみ。**再現推奨はK6。K3の炎上エンジンは推奨しない。**

## 3. システムプロンプト・ブループリント（自動化する場合）

GPTs / Claude Project / API に実装するときの構造:

```
## ロール
あなたは{ジャンル}で{実績数値}を持つ発信者。口調: {文体サンプル}

## 絶対ルール（減点回避）
（共通エンジン7のチェックリストをそのまま貼る）

## 生成手順
（共通エンジン1〜6をそのまま貼る）

## 出力形式
型違いで3案。各案に「型名」「狙うシグナル（リプ往復/ブクマ/RT）」
「投稿後60分にやること」を付記。

## Few-Shot（最重要）
{post-corpus.md から同ジャンル・同型の実ポスト3〜4本を貼る}
{運用開始後は自分の当たりポストに差し替えていく}
```

- Few-Shotの質が出力の質を決める。post-corpus.md の実ポストを初期値にし、運用で得た自分の当たりポストへ順次入れ替える。
- **AI出力をそのまま投稿しない**。2026年アルゴはテンプレ量産文・機械的な投稿時刻を減点する。AIで骨格生成 → 人間が固有名詞・実体験・端数込みの数字を注入、が唯一の持続可能解。投稿時刻も毎回ずらす。

## 4. ネタ供給パイプライン（ジャンル→ネタの仕組み化）

週次でネタをストックする検索コマンド（X検索）:

```
{ジャンルKW} min_faves:500                        … ジャンル内バズ実例
{ジャンルKW} min_faves:100 min_retweets:50        … 拡散型に絞る
from:{競合アカ} min_faves:300                     … 競合の当たり投稿だけ抽出
{ジャンルKW} min_faves:300 since:2026-06-01       … 鮮度確保
lang:en {ジャンルKW} min_faves:5000               … 海外バズ（翻案ネタ元）
```

ネタ元の優先順:
1. **時事・元情報**（ろじん式の中核）: ニュース・有名人の実績・新機能に解説を乗せる
2. **Q&Aサイト（Yahoo!知恵袋等）**: 需要が実証済みの質問をフックに、回答を本文に
3. **海外バズの翻案**: 単純翻訳ではなく日本文脈に置換（Grok自動翻訳標準化で単純翻訳は陳腐化済み）
4. **過去バズのリライト**: 構造だけ抜いて題材を差し替え。切り口の変え方は「対象者を変える（初心者→中上級者）/形式を変える（文章→チェックリスト→比較表）/立場を変える（称賛→懸念→体験談）」

収集したバズ実例は「型×ネタ」のスプレッドシートに貯める＝Few-Shot素材の供給源。

## 5. 週間運用ループ

```
月: 共感型（週初の憂鬱に共感）
火水: 有益型（Buffer 870万ポスト分析で火9時・水10時が最強帯）
木: 元情報+解説型（R1/R3）
金土: 体験談・ストーリー型（K1/K2の弱毒版）
日: 問いかけ型（リプ収集）
```

- 頻度: 1日1〜3本の高密度投稿。薄い5本は連投減衰（Author Diversity Penalty）で損。
- 投稿後60分はリプ全返信（リプ往復＝いいね150倍のシグナルを手動量産）。
- バズったら同テーマで連投し優遇期間を回収。当たり投稿はアレンジ再投稿で再成長。
- 週次レビュー: 保存率2%以上を当たり判定（Levela基準）→ 当たり構成を型登録 → Few-Shotに昇格 → 題材を替えて横展開。
- KPI: インプ・フォロワーは中間指標。最終KPIは「1投稿あたりの見込み客リスト獲得数」（ろじん式。1日3〜5リストで月200万円が成立するという本人談）。
```
