# ろじん式 X運用メソッド

ろじん（本名: 湯川新太郎、X: @fiction_log / 旧 @BuzzLogicCEO）。株式会社BuzzLogic元代表。X顧問を累計900社に提供し、2026年1月にX顧問事業を株式会社Levelaへ約3.04億円で事業譲渡、Levela CXO（X事業推進責任者）に就任。自己申告実績: 本垢1日平均30万インプ、Xで月1,000万円以上の売上を1年以上継続。

- 出典: [Levela参画ニュース](https://levela.co.jp/news/rojin-joins-levela/)、[PR TIMES](https://prtimes.jp/main/html/rd/p/000000002.000164510.html)、[X顧問のご案内(note)](https://note.com/chiharuchi/n/n3083150e4f97)
- 注意: 「10日で10万フォロワー」はTikTokでの実績（Xではない）。

## 1. 中核思想

### 実績がない人は持論を語るな（元情報の提供に徹する）
実績・ブランディングが確立していないアカウントが持論を語っても見られない。**注目が集まっている元情報（他者の実績・ニュース・一次情報）を提示し、「ここがすごいんだよ！」と解説する**のが誰でも伸ばせる方法。令和の虎二代目主宰・林尚弘氏が「ろじんさんをフォローするとXを伸ばすヒントが載っている」と名指しで紹介した手法。

観察された実例の構成:
1. 1行目で対象を提示
2. 「①②③」の番号列挙で凄さを分解
3. 「①だけならまだしも、②③は凄すぎる」と逆説で深掘り
4. 短文改行の多用

### 権威称賛→本人リポスト誘発
有名人・経営者の凄さを具体的に分析して褒めるポストを書く → 本人が「つい」リポストする → 本人のフォロワーに露出。林氏本人が「こうやって林社長がすごいと書かれるとついリポストしたくなる。このノウハウは正しいw」と種明かししている。

### ファンダとテクニカル
SNS運用は「ファンダ（発信者としての経験・中身）」と「テクニカル（運用技術）」の2要素。テクニカルだけでは頭打ちする。

## 2. アルゴリズム観・診断フレーム

- **「フォロワーの質は関係ない。質の悪いフォロワーでも集めろ」**。YouTube以外のSNSは「良いものは伸びる／微妙なものは伸びない」＝ポスト単体の評価がインプを決める。
- 世間が挙げる「プロフィールが微妙・投稿時間帯・実績・フォロワー数・いいね周り」は**本質的な改善にならない**と明確に否定。
- フォロワー3,000のサブ垢で4日間10万インプを実演し、「フォロワー数が少なくてもインプは取れる。結局はX運用の上手さ」と主張。
- 長文ポスト・動画挿入などの「アルゴリズム最適化技術」より、**参入している市場（ジャンル）の規模認識**が伸び続ける人と衰退する人の分岐点。

### オワコン化の3パターン（診断に使う）
1. 時代への適応遅れ（昔のノウハウにあぐら）← 大多数はこれ。一時的な収入増→慢心→感度低下が典型
2. 旬の終焉
3. モチベ低下による逃避

危機感を持つ人とコンテンツ力が強い人は復活・継続成長できる。

## 3. ジャンル選定

Xで成果が出やすいジャンル（本人談）:
- 物販（Yahoo!ショッピング・eBay）
- SNSコンサル（X/YouTube/Instagram）
- 恋愛系
- スキル習得（プログラミング・デザイン）
- 広告運用・セールス系

逆に、スピリチュアル等の抽象的ジャンルは**Xの論理的ユーザー層と相性が悪い**。

ポジショニング例: 自身の講座は「初心者向けが飽和しているので中上級者向けに絞る」ことで成功。

## 4. KPI設計とマネタイズ導線

- **「インプレッションがどれだけあってもリストが取れなきゃ意味がない。1日3〜5リストでも月200万円は余裕」** — 最終KPIはフォロワー数でもインプでもなく、**1投稿あたりの見込み客リスト獲得数**。
- 教える順序: 「Xでリストを取る感覚」→「商品設計」。
- 導線: リスト獲得 → 商品提案 → 契約。
- 売り方は「引きの営業」＝ゴリ押しせず「この人の出すものは買おう」というブランディング状態を先に作る（清潔感・喋り方・ふるまい・心理理解）。
- **受講生の成果ポストを自分がリポストするだけで講座が広がった** — 顧客の成果＝最強の広告。
- プレゼント企画（giveaway）常用アカウントは「オワコン間近」と批判する立場。

## 5. 運用体制（顧問で提供している仕組み）

- ロードマップ実践 → 電話コンサルで改善 → 実践、の反復改善型。
- ポスト添削を個別LINEで実施。月4回のオフライン個別コンサル会。
- 旧Twitter顧問時代は「いいねし合う部屋」（相互いいねグループ）と「ろじん垢による反応」で初速エンゲージメントを組織的に作る仕組みを提供していた（※現在のアルゴリズムでは相互いいね水増しは評価スコアを毀損するリスクがある点に注意）。
- Levela参画後: スタッフの投稿を能動的にチェック・フィードバックし、ゼロから100万インプ超ポスト・フォロワー1,000人超アカウントを量産（同社発表: みづき氏605万インプ等）。
- 型のテンプレ化: AIポスト作成ツール「myろじん」を販売（「ろじんの手動ポスト×0.8のパワーを量産」「1ポスト2分」）＝ポストの型は明文化・機械化可能なレベルまで定式化されている。
